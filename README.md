# 组织行为学 · 练习题库

天津大学《组织行为学》（2026 秋冬）期末复习题库，810 道题，11 个模块。

单文件静态站点，无需后端、无需注册，打开即用。

## 功能

- **810 道题**：覆盖绪论、个体心理与行为、个人与组织的关系、动机与激励、群体心理与行为、团队、领导、沟通、组织文化、组织学习与创新、组织变革与发展
- **逐题刷题**：一屏一题，支持键盘 ← → 翻页
- **即时判分**：点选项立刻判对错，自动展开答案与解析
- **错题本**：做错自动收录，重做答对后自动移出
- **随机顺序**：可在全部题目或当前模块内打乱
- **个人报告**：总进度、正确率、各章掌握度、题型表现、待复习清单，可打印
- **多人共用一台设备**：左上角可切换使用者，各自记录互不干扰
- **手机适配**：手机、平板、桌面三档响应式

## 使用

直接用浏览器打开 `index.html`，或访问 GitHub Pages 地址。

首次进入填写名字（或学号），之后所有答题记录都记在这个名字下。
点左上角的名字可以切换使用者，重新输入同一名字即可切回原记录。

## 数据说明

- 答题记录保存在浏览器的 **localStorage**，不上传任何服务器
- 换设备、换浏览器、清理浏览器数据后会丢失
- 想换设备继续，可在同一浏览器导出（暂未提供导出功能，如有需要可加）

## 题目与答案来源

- 题干来自智慧树课程练习（11 个模块共 810 题）
- 答案与解析由 AI 依据课程课件与教材整理，**仅供参考**，个别细节以任课教师课件为准
